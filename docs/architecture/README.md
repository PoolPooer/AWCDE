# Architecture

This directory contains the long-term architectural design of AWCDE.

Unlike the `specs/` directory, which captures implementation planning for a
specific MVP or feature, this directory documents the enduring architecture of
the platform.

Typical contents include:

- System architecture
- Workload Signature Specification
- Recommendation Engine design
- Knowledge Base design
- Telemetry Provider architecture
- High-level diagrams
- Future architecture proposals

These documents describe *how AWCDE works*, independent of implementation
details.
