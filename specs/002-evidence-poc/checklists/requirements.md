# Validation checklist

All checks are pending experimental work.

- [ ] Charter reviewed and scope confirmed.
- [ ] Environment, model, runtime and two tool versions recorded.
- [ ] Actual workload equivalence and metric semantics checked.
- [ ] Queue metric definition and telemetry coverage verified.
- [ ] Pilot separated from validation; criteria frozen.
- [ ] Repeated runs and uncertainty analysis completed.
- [ ] Raw artifacts and hashes preserved; sources traceable.
- [ ] Known mismatches and missing evidence tested.
- [ ] Substantive reanalysis reproducible.
- [ ] Added value compared with simple baselines.
- [ ] Proceed, pivot or stop decision recorded.
